## Selected projects

### 📚 [BuildLearn — construction learning platform](https://github.com/AkroutMohamed/buildlearn-formation-platform)

My summer internship project: a French-language platform for discovering courses, learning, taking quizzes, and managing training content. It includes a document-grounded chat feature built with Ollama and Qdrant. **Stack:** Next.js, React, TypeScript, FastAPI, PostgreSQL.

### 🤖 [HireBot — AI-assisted recruitment](https://github.com/AkroutMohamed/hirebot-recruitment-platform)

A collaborative project with [Oussema Hidouri](https://github.com/oussema2003). HireBot brings together video authenticity checks, language processing, and voice analysis to support the review of video applications. **Stack:** Django, React, TypeScript, PyTorch, MariaDB.

### 📊 [Explainable Credit Default Risk Lab](https://github.com/AkroutMohamed/credit-risk-xai)

An educational decision-support prototype for exploring credit-default data, comparing models, and explaining predictions with SHAP and LIME. **Stack:** Python, Streamlit, FastAPI, scikit-learn.
